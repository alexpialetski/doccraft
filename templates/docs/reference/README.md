# Reference

Long-form engineering notes — **runbooks**, **architecture descriptions**,
**eval harness documentation**, **integration guides**, **operational
playbooks**, **pricing / capacity references**. Material that is more
substantial than an ADR (which is a decision) and more durable than a
research note (which is exploration).

When proposing a reference doc via `doccraft-session-wrap`, the path is
`docs/reference/<topic>.md`. Update this README to link new entries when
the folder grows enough that scanning the directory listing alone stops
being useful.
