# Research

Exploration, comparison, and synthesis notes that **have not yet
condensed into a "we decided X"** — vendor / library comparisons,
literature notes, prototype findings, dataset surveys, open questions.

When the work crystallises into a chosen direction, promote it to an
[`adr/`](../adr/README.md) entry (the decision) plus, if needed, a
[`reference/`](../reference/README.md) entry (the long-form
documentation of what was chosen). Research notes stay here as the
provenance.

When proposing a research note via `doccraft-session-wrap`, the path
is `docs/research/<topic>.md`. Update this README to link new entries
once the folder grows.
